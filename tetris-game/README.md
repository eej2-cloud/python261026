# Tetris Game

This project is a simple implementation of the classic Tetris game using Python's Tkinter library.

## Overview

Tetris is a tile-matching puzzle game where players manipulate falling tetrominoes to create horizontal lines without gaps. When a line is completed, it disappears, and the player earns points. The game ends when the stack of tetrominoes reaches the top of the playing field.

## How to Run the Game

1. Ensure you have Python installed on your machine. You can download it from [python.org](https://www.python.org/downloads/).
2. Install the Tkinter library if it is not already included with your Python installation. Tkinter usually comes pre-installed with Python.
3. Clone this repository or download the `DemoTetris.py` file.
4. Open a terminal or command prompt and navigate to the directory containing `DemoTetris.py`.
5. Run the game using the following command:

   ```
   python DemoTetris.py
   ```

## Game Controls

- Use the arrow keys to move the tetrominoes:
  - Left Arrow: Move left
  - Right Arrow: Move right
  - Down Arrow: Move down
  - Up Arrow: Rotate the tetromino
- The game will automatically drop the tetrominoes at a set interval.

## Dependencies

- Python 3.x
- Tkinter (usually included with Python)
